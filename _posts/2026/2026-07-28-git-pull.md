# Git Pull

在 Git 目录中放下面的文件，双击执行 Pull 拉取最新代码。  
  
文件名: git_pull.bat
  
```sh
echo off

git pull

choice /d y /t 5 > nul
```

文件名: git_pull_all.bat
  
```sh
echo off

git pull

REM cd ..\

REM cd Directory

REM git pull

choice /d y /t 5 > nul
```
